CATATAN:
- Format .jpeg dan .png juga otomatis dicoba kalau .jpg tidak ketemu.
  Contoh: kalau kamu punya "Nasi Katsu.jpeg", rename jadi "nasi-katsu.jpeg" tetap tampil.
- Kalau file belum ada, otomatis tampil kotak "Foto segera hadir" — bukan gambar rusak.
- Ukuran disarankan: landscape/persegi, min. 800px, < 500KB agar web cepat.
- Setelah tambah foto, refresh browser (Ctrl+R).

Hapus file .gitkeep ini boleh setelah ada foto, atau biarkan saja.
